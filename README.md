# Real-World Quant Projects

This repository contains applied quantitative finance projects focused on financial data analysis, volatility modeling, systematic trading research, backtesting, and risk analytics.

The goal of this repository is to build a practical quant research portfolio that demonstrates the ability to work with real market data, develop research hypotheses, test trading signals, evaluate model performance, and communicate results clearly.

## Purpose

This repository is designed to showcase practical skills relevant to quantitative research, financial technology, systematic trading, investment research, and data-driven finance roles.

## Core Skills Demonstrated

- Python for financial analysis
- Market data collection and cleaning
- Return and volatility analysis
- Time-series modeling
- Statistical research methods
- Backtesting and performance evaluation
- Risk and drawdown analysis
- Machine learning for financial data
- Clear research documentation

## Projects

### 1. Volatility Forecasting System

This project analyzes and forecasts market volatility using real financial market data.

Initial focus:

- Download historical market data
- Calculate daily returns
- Estimate daily and annualized volatility
- Compute rolling realized volatility
- Visualize volatility behavior over time

Future extensions:

- EWMA volatility model
- GARCH volatility model
- Machine learning volatility forecasting
- Forecast error comparison
- Risk management interpretation
